# Data

The MIT license in this repository covers the code. Dataset files follow their original licenses.

Tracked data:

- `data/pb_cf/`: PhoneBook data and CounterFact experiment subsets/metadata used by the PB/CF experiments.
- `data/paper_dataset/paperQA.json`: PaperQA metadata used to build the PaperQA training files.

Generated locally:

- PaperQA training files under `paperqa/data/`
- NarrativeQA and QuALITY local data under `narrativeqa/data/` and `qual/data/`
- training results, evaluation results, and config files
